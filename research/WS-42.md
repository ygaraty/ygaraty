## Question

Experiment 122 measured 6.9× faster attention at 1k positions (Kolibri-1 decode 111 → 30.5 ms per token) but failed its frozen gate on a long-prompt gap the old splits share. What does it take to make the split the default safely?

## Prediction

Short prompts within 2e-3 of the reference; split 64 and split 512 within a few 1e-3 of each other on the long prompt (only the summation order changes).

## Gate (proposed; freeze before running)

**Works, now default** if: (1) 19-token prompts: 32/32 tokens equal to the reference, logits within 2e-3, for Kolibri-1 and one dense model; (2) 1,002-token prompt: split 64's logits within 1e-2 of split 512's (relative to the largest) at every step, and the same tokens except where split 512's top-2 margin is under 0.05; (3) the speed of experiment 122 reproduced (attention at least 3× faster at 1,024 positions). Otherwise **Rejected**.

## Protocol

Needs WS-41 first only if WS-41 finds a bug in the attention path itself. The pipeline writes logits per step, so (2) compares the two arms' logit files directly.
