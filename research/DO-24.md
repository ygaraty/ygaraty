## Protocol

Use known hardware capacities and measured stage costs. Compare equal layer counts, tuned fixed unequal ranges and a measured-cost selector that may choose replicas. Include stable load and scripted resource changes. Hold kernels/precision constant. Count model loading and KV transfer/replay costs; do not move active sessions for free. Use held-out workload/topology traces. Browser participation depends on DO-23. A future RL comparison requires a separate justified experiment.

All deciding runs take place on the authorized dev server or remote test machines,
not this simulation-only workstation. This entry authorizes planning only, not
provisioning. Host inventory, budget (if rented), teardown deadline, checkpoint
hashes and exact runner commands are TBD. No services or workloads were started.

Use pinned prompts of 128/1024/3968 tokens and up to 128 generated tokens for
single-session comparisons unless the frozen protocol explicitly changes them.
Record EOS and actual lengths. Start with at least five warm measured repeats,
report variability and repeat borderline outcomes; do not treat a handful of
session summaries as a reliable request-tail estimate for load tests. Use
monotonic clocks, synchronized GPU timing where needed and explicit timing
boundaries. Save commands, source revision, input hashes and raw traces under
`runs/experiments/DO-24/<host>-<timestamp>/`. Commit the driver and analysis code.
